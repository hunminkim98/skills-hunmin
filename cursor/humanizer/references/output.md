# Output

Use this in chat. Do not write a report file unless the user named a path to edit.

## Rewrite (default)

Show the rewritten prose first. For a file edit, name the path and keep the chat short.

Then a short list, at most five lines:

- What you actually changed (plain language, not pattern IDs)
- What you left because it was already fine or protected
- Change-rate warning only when it is 30% or more

No analysis essay. No before/after novel. If the user asks what you looked for, answer in a follow-up.

## Already clean

Say it is already readable. Offer at most two optional nits. Do not rewrite for sport.

## Detect only

List the tells you found, with a short quote each, ordered by how much they warp the reading. Do not rewrite.

## File edit

Edit prose only. Leave code, frontmatter, and commands untouched. After the edit, do not paste the whole file back into chat.
