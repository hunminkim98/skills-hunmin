# Report shape

Use this in chat. Do not write it to disk.

## Path

The stages you ran, in order, and one sentence why. Name stages you skipped and why. Example: `deep-analyze only — the question is a lock site in this repo.`

## Answer

What the user should take away. If discussion ran, this is the recommendation. If not, this is the factual brief's answer. Do not hide a skip behind a fake "we should consider both."

## From each stage

A short block per stage that actually ran, in the child's own shape (do not re-genre it):

- `deep-research` → What we know / Conflicts / Uncertain
- `deep-analyze` → Answer / Evidence / What would make this wrong / Gaps
- `discussion` → Recommendation / Why not the alternatives / Constraints / Contested / Risks

Collapse repetition. The Answer section above owns the headline. These blocks hold the evidence.

## Sources actually opened

Files with line ranges and URLs the stages opened. No unread titles.

## Next

Only if the user must do something: install a missing sibling, answer a discussion gate already asked, or say they want implementation. No leftover "future work" list.
