# Report shape

Use this in chat. Do not write it to disk.

## Recommendation

The path to take, in a few sentences. Name the single biggest reason it beat the others.

## Why not the alternatives

One short paragraph per serious alternative. Include who argued for it and why it lost.

## Constraints you set

The user's answers that ranked the options.

## Contested

What is still unresolved, and what would resolve it.

## Risks

Residual risks if we follow the recommendation.

## Sources the experts actually used

Files and URLs, not unread names.
