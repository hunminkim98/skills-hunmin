# Report shape

Use this in chat. Do not write a second copy of the memo into the reply.

## Answer

One short paragraph: how many nominees, how many stayed (3–5), how many moved (1–2), and the memo path if anything moved.

## Stayed (3–5)

Path, score, one line. Skip this list when it is long and nothing was borderline. Always mention a path you scored 3 because you were unsure.

## Moved to garbage (1–2)

Path, score, original location. Point at `garbage/YYYY-MM-DD/MEMO.md`.

## Left alone

Never-move hits, secrets, or "this is source, not output."

If nothing looked like output debt, say that. Do not create `garbage/` for an empty run.
