# Citations

A claim is allowed only when you opened the page. Training memory can suggest a query. It cannot fill a number, a date, or a quote.

## Labels

| Kind | Use for |
|---|---|
| official | Vendor docs, specs, statutes, primary data the issuer published |
| academic | Papers, preprints you opened, conference pages |
| journalism | Named outlets that report, not rewrite a press release only |
| community | GitHub issues, forums, blogs, social posts |
| other | Aggregators, undated slides, anything that does not fit |

Mark `[single-source]` when only one opened page supports the claim. Mark `unverified` when you could not open a source and then drop the precise number.

## Conflicts

If two opened pages disagree, write both. Name the disagreement. Do not pick a winner because one page is newer or louder unless the pages themselves give a reason (retraction, version, scope).

## Freshness

Put an as-of date on timed claims (pricing, versions, incidents, law). If the page has no date, write `unknown` and do not call it current.

A post older than two years can still explain a mechanism. It cannot, by itself, prove "the ecosystem now."

## Do not

- Cite a SERP snippet as if it were the article
- Cite a URL you could not fetch
- Paste long copyrighted passages; one short quote is enough when the wording is the claim
- Launder a paywall by quoting a scrape of the full piece
- Use the user's private accounts to "discover" what they already know
