# wiki-for-llm

[English](../en/wiki-for-llm.md) · [문서 홈](README.md) · [SKILL.md](../../cursor/wiki-for-llm/SKILL.md)

이번 대화의 작업을 기록해, 나중에 맥락을 다시 설명하지 않게 합니다. 채팅은 짧게 두고, 다음 에이전트가 읽을 내용은 위키에 둡니다.

## 왜 만들었나요

긴 에이전트 세션은 **인지 부채**를 남깁니다. 건드리지 말라고 한 것, 빠진 테스트, 중간에 굳힌 제약을 당신이 기억하고, 다음 채팅은 차갑게 시작해 다시 묻습니다.

이 스킬은 그 부채를 디스크에 옮깁니다. 사용자는 위키를 안 읽어도 막히지 않아야 합니다. 다음 에이전트는 당신을 심문하는 대신 노트를 열어야 합니다.

Karpathy식 LLM 위키가 **아닙니다**. 논문을 `raw/`에 넣고 개념 페이지로 컴파일하지 않습니다. 재료는 **이번 채팅과 이번 변경**입니다.

UmFit 전용도 아닙니다. 기본 폴더는 이식 가능합니다. 레포에 이미 `llm-wiki/UmFit/02-Tasks` 같은 관례가 있으면 그 트리를 따르고, 두 번째 나무를 만들지 않습니다.

## 원리

코드, 문서, 아키텍처, 워크플로, Git 상태, 또는 다음 에이전트가 따라야 할 결정이 바뀌면 **물어보지 않아도** 씁니다. 지워서 다시 돌아오면 안 되는 것, 재사용할 개선도 마찬가지입니다.

읽기 전용 질문, 오타, 내구성 있는 상태를 남기지 않은 탐색은 건너뜁니다. 다만 그 탐색이 중요한 결정을 남겼다면 기록합니다.

이미 있는 볼트를 찾습니다 (`llm-wiki/`, `tasks` / `02-Tasks` / `decisions` / `03-Decisions`, 또는 `AGENTS.md`의 closeout 경로). 있으면 그 레이아웃과 템플릿을 씁니다.

없으면 이것만 만듭니다.

```text
llm-wiki/
  tasks/
  decisions/
  cleanup/
  improvements/
  templates/
  index.md
```

템플릿은 스킬의 `references/`에서 복사합니다. 새 노트 이름은 `YYYY-MM-DD-descriptive-slug.md`입니다. 레포가 이미 ADR 번호를 쓰면 그 관례를 유지합니다.

노트마다, 레포 형식이든 이식 템플릿이든 들어가야 하는 것: 사용자 요청, 대화에서 굳힌 결정, 건드린 경로, 바꾼 것, 일부러 안 바꾼 것, 검증 명령과 결과(또는 `needs-verification`), 후속. 시크릿과 머신 로컬 절대 경로는 넣지 않습니다.

채팅과 위키:

- 위키: 차가운 에이전트가 이어서 할 수 있을 만큼
- 채팅: 무엇이 바뀌었는지, 어떻게 검증하는지, 노트 경로. 위키 본문을 다시 붙여 넣지 않음

같은 작업의 열린 노트를 갱신하는 쪽을 선호합니다. 관련 노트를 연결합니다. 명령 결과를 지어내지 않습니다.

### 첫 실행과 AGENTS.md

`npx skills add`는 `AGENTS.md`를 **고치지 않습니다**.

더 자세한 위키 closeout이 없는 레포에서 이 스킬이 **실제로 처음 실행될 때**, `references/agents-md-snippet.md`의 한 줄을 넣을 수 있습니다. 조건은 `AGENTS.md`가 이미 있거나, 레포 세팅을 요청한 경우입니다. 더 풍부한 규칙을 덮지 않습니다. 그 프로젝트가 이미 이 스킬을 가리키지 않는 한, 기존 closeout을 다시 쓰지 않습니다.

## 언제 쓰나요

실제 작업이 끝나면 그냥 돌아가게 두면 됩니다. 지금 노트를 쓰려면 `/wiki-for-llm`을 쳐도 됩니다.

“이 함수가 뭐 해요?”에는 쓰지 마세요. 오래 남을 결정이 없는 한 그렇습니다. URL을 `raw/`에 넣는 Karpathy 흐름과도 다릅니다.

슬래시 전용 스킬과 달리, 설명과 맞으면 **스스로 켜질 수** 있습니다. 새 레포에서는 `AGENTS.md` 한 줄이 있으면 더 믿을 만합니다.

## 설치

```bash
npx skills add hunminkim98/skills-hunmin --skill wiki-for-llm --agent cursor
```

이 머신 모든 프로젝트에서 쓰려면 `--global`을 붙입니다. 위키 규칙이 없는 새 템플릿 레포라면 [`references/agents-md-snippet.md`](../../cursor/wiki-for-llm/references/agents-md-snippet.md)를 직접 붙여도 됩니다.

## 사용 방법

평소처럼 일하면 됩니다. 끝에 짧은 채팅 요약과 `llm-wiki/tasks/2026-08-20-....md` 같은 경로가 보여야 합니다. 전체 기록이 필요하면 그 경로를 여세요.

새 레포에서는 첫 실행이 `AGENTS.md` 한 줄을 넣을 때까지 기다리거나, 직접 넣으면 됩니다. 그다음부터는 매번 `/wiki-for-llm`을 치지 않아도 에이전트가 스킬을 불러옵니다.

## 다른 스킬과

- [discussion](discussion.md) 뒤에 결정을 디스크에 남기려면 따로 요청하세요. discussion 자체는 파일을 쓰지 않습니다.
- [deep-analyze](deep-analyze.md)는 읽기 전용이라 이 노트를 쓰지 않습니다.
- 바깥 아티클을 넣는 용도가 아닙니다.

## 한계

볼트는 적힌 만큼만 쓸모가 있습니다. 검증을 건너뛰었으면 노트에 그렇게 써야 합니다. 이미 쓰지 않는 레포에 UmFit 경로를 만들지 않습니다. 있는 위키 옆에 두 번째 위키를 키우지 않습니다.
